# s2sat: спутники на снимках Sentinel-2

Контекст и план работ лежат в `HANDOFF.md`. Код пилота (Pyodide) находится в `pilot_code/`, он нужен только как справка.

```
pip install -e .[test]
python -m pytest -q                       # включая сетевую регрессию МКС (~20 с с кэшем)
python scripts/iss_regression.py --pilot-tle
```

Модули `s2sat/`:
- `orbits.py`: TLE (CelesTrak с кэшем, токенный парсер для `tle_raw.txt`), `sgp4`, TEME→ITRS через skyfield, Солнце (de421).
- `crossings.py`: перебор пересечений «веер Sentinel × объект» (временно заменяет Equant).
- `geometry.py`: плоскость полосы, видимый трек (векторизованная бисекция), WGS84, pyproj.
- `s2meta.py`: углы из `MTD_TL.xml`, корни по полосам и детекторам.
- `imagery.py`: pystac-client (Earth Search) и окна COG через rasterio/WarpedVRT; кэш в `data/cache`.
- `detect.py`: z-карты, E-карты, совместный поиск сдвига, нуль-тест.
- `pipeline.py`: полный прогон одного события. `viz.py`: картинка.

### Детектор (`method="glrt"`, по умолчанию)
1. Фон удаляется по самому снимку: каждая полоса предсказывается робастной блочной регрессией по
   остальным полосам того же снимка (`bgsub.predict_band`). Снимок другой даты не нужен.
2. Маска облаков/теней/насыщения из SCL с запасом 200 м (параллакс облаков).
3. Согласованный фильтр, нормировка шума по блокам 500 м, удаление синфазной составляющей
   (структура, видимая во всех полосах в одной точке, — это сцена).
4. Допуск положения полосы ±50 м (погрешность модели углов) как параметр-помеха.
5. GLRT модели заслонения: отклик полосы `a − f·G_b`, где `G_b` — яркость фона. Объект закрывает
   землю, поэтому контраст = f·(ρ_спутника − ρ_фона) и меняет знак между полосами.
6. Перебор фазы вдоль орбиты с шагом по фактическому увеличению + 2D-сдвиг; нуль-тест.

Чувствительность (вставки в реальную сцену над сушей, Китай, известная орбита):
старый детектор не видит 40×40 м даже при +400 DN; новый находит +400 DN (15.6 / 7.6, сдвиг точный).
«Starlink» по модели заслонения (ρ = 0.055, f = 0.5, 40×40 м) находится в сценах-промахах
37359 (Аризона: 18.1 / 9.0) и 33770 (Оклахома: 19.1 / 12.6).

### Физика, которая определяет, виден ли объект (найдено на данных)
* **Увеличение ошибки орбиты на снимке** = 0.5…4.3 км на 1 км ошибки вдоль орбиты (не 2–2.5×):
  у медленных попутных пролётов момент пересечения веера сильно зависит от фазы. Отсюда
  адаптивный шаг перебора фазы (`gain_m_per_km`).
* **Слепые зоны шахматных детекторов.** Соседние детекторы смотрят вперёд/назад (α скачет,
  напр. −0.58° → +0.38°). При части фаз объект не попадает ни в одну полосу
  (`scripts/visibility.py`). STARLINK-37359: фазы −4…0 км слепые, орбиты GP/SupGP ставят его в 0 —
  объекта на снимке нет.
* **Контраст.** Starlink тёмный (ρ ≈ 0.055 по 31550). Над океаном контраст положительный во всех
  полосах; над сушей может быть ≈ 0 или менять знак между полосами.
* **Push-broom сжимает/растягивает изображение вдоль трассы** в |v_g/(v_g − v_img)| раз: на быстром
  встречном пролёте объект — одна строка (сигнал слабый), на медленном попутном — длинный штрих
  (сигнал сильный). Медленные пролёты самые выгодные, но за сутки все они пришлись на океан/облака.

### Equant
Актуальная версия: `hex358/cull`, ветка `decay-study` (CUDA; на CPU не запускается без порта
варповых операций). `scripts/bench_equant.py` сравнивает Equant (`equant.screen`, радиус 650 км) с
перебором: время, полнота, число окон на пересечение. Перебор: 3 Sentinel-2 × 13.9 тыс. LEO × сутки ≈ 0.7 мин CPU.
Ценность Equant здесь — масштаб (все сенсоры × каталог × годы) и гарантированные фазовые интервалы,
которые прямо задают диапазон поиска на снимке и пересекаются с картой слепых зон.
