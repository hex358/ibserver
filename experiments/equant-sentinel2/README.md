# s2sat: спутники на снимках Sentinel-2

Контекст и план работ лежат в `HANDOFF.md`. Код пилота (Pyodide) находится в `pilot_code/`, он нужен только как справка.

```
pip install -e .[test]
python -m pytest -q                       # включая сетевую регрессию МКС (~20 с с кэшем)
python scripts/iss_regression.py --pilot-tle
```

Модули `s2sat/`:
- `orbits.py`: TLE (CelesTrak с кэшем, токенный парсер для `tle_raw.txt`), `sgp4`, TEME→ITRS через skyfield, Солнце (de421).
- `crossings.py`: перебор пересечений «веер Sentinel × объект» (временно заменяет Equant).
- `geometry.py`: плоскость полосы, видимый трек (векторизованная бисекция), WGS84, pyproj.
- `s2meta.py`: углы из `MTD_TL.xml`, корни по полосам и детекторам.
- `imagery.py`: pystac-client (Earth Search) и окна COG через rasterio/WarpedVRT; кэш в `data/cache`.
- `detect.py`: z-карты, E-карты, совместный поиск сдвига, нуль-тест.
- `pipeline.py`: полный прогон одного события. `viz.py`: картинка.

### Как устроено (кратко)
1. Пересечения «веер Sentinel-2 × каталог» (перебор; на GPU — Equant, `scripts/bench_equant.py`).
2. Фильтр по контурам снимков: весь каталог STAC за окно одним запросом, без снимка/с облаками — отброс.
3. Окно по фазе — по типу объекта и возрасту TLE (Starlink: по расхождению GP/SupGP, до ±25 км; прочие ±1.5–6 км).
4. Фон удаляется по самому снимку (каждая полоса — регрессия по остальным), маска облаков SCL.
5. Банк согласованных фильтров (круг + отрезки поперёк трассы), допуск ±30 м на полосу.
6. GLRT модели заслонения: контраст полосы = f·(ρ_объекта − ρ_фона), спектры «серый» и «красный» (Starlink).
7. Прогноз SNR по теории для каждого события и диагноз:
   `detected` / `blind_nominal` (слепая зона детекторов) / `too_faint` / `borderline` (виден только при удачной
   ориентации) / `MISSED` (должен быть виден — автоповтор с окном до ±60 км и окном сдвига ×2).
8. Совместный поиск по нескольким пересечениям одного объекта (`scripts/joint.py`): одна поправка орбиты a + b·t.
