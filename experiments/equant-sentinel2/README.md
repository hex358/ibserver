# s2sat: спутники на снимках Sentinel-2

Контекст и план работ лежат в `HANDOFF.md`. Код пилота (Pyodide) находится в `pilot_code/`, он нужен только как справка.

```
pip install -e .[test]
python -m pytest -q                       # включая сетевую регрессию МКС (~20 с с кэшем)
python scripts/iss_regression.py --pilot-tle
```

Модули `s2sat/`:
- `orbits.py`: TLE (CelesTrak с кэшем, токенный парсер для `tle_raw.txt`), `sgp4`, TEME→ITRS через skyfield, Солнце (de421).
- `crossings.py`: перебор пересечений «веер Sentinel × объект» (временно заменяет Equant).
- `geometry.py`: плоскость полосы, видимый трек (векторизованная бисекция), WGS84, pyproj.
- `s2meta.py`: углы из `MTD_TL.xml`, корни по полосам и детекторам.
- `imagery.py`: pystac-client (Earth Search) и окна COG через rasterio/WarpedVRT; кэш в `data/cache`.
- `detect.py`: z-карты, E-карты, совместный поиск сдвига, нуль-тест.
- `pipeline.py`: полный прогон одного события. `viz.py`: картинка.
