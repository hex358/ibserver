# Ocellus: характеризация объектов на орбите по снимкам — проект системы

Цель — из каждого пролёта объекта через кадр Sentinel‑2 (и других съёмочных систем) получать измеренные физические
параметры объекта, а не картинку. Параметры должны быть нужны тем, кто:
- ведёт каталог и уточняет орбиты (TLE, OD);
- оценивает риск столкновений;
- готовит увод мусора (ADR);
- следит за состоянием аппаратов.

Каждый объект проходит **один и тот же конвейер**. Всё, что зависит от объекта, берётся из данных:
- каталоги (SATCAT, GCAT, DISCOS);
- модели и их кинематика;
- законы ориентации класса;
- сами снимки.

Кода под конкретный аппарат нет.

---

## 1. Что можно измерить и почему это возможно

Sentinel‑2 — сканер (push‑broom). 13 полос снимают одну и ту же точку в разные моменты: между первой и последней полосой
проходит до ~2 с. Пиксель 10 м (B2–B4, B8), 20 м (B5–B7, B8A, B11, B12), 60 м (B1, B9, B10).

Один пролёт объекта поэтому даёт:
- **10–13 положений во времени**: пятно каждой полосы снято в свой момент;
- **10–13 спектральных отсчётов яркости**;
- **10–13 силуэтов** с разных моментов. За 2 с кувыркающаяся ступень поворачивается на заметный угол.

| Параметр | Из чего | Точность на пролёт (оценка) | Кому нужен |
|---|---|---|---|
| Положение на эпоху (вдоль, поперёк, по радиусу) | центры пятен полос + дальность | 2–5 м поперёк луча; вдоль следа — по времени полос | каталог, OD, риск столкновений |
| Ошибка TLE на эпоху, смещение по времени | сравнение с прогнозом SGP4 | вдоль следа — метры вместо сотен метров у TLE | уточнение TLE / SupGP |
| Скорость | наклон положений по 10 моментам | единицы м/с | OD, обнаружение манёвров |
| Размеры, конфигурация | силуэты в полосах + каталог моделей | ~ 1/3 пикселя по краю ярких объектов | идентификация, раскрытие панелей, отказы |
| Ориентация: закон (штатная / нештатная) | выбор закона по отложенным полосам | дискретный выбор, значимость в эффективном χ² | статус аппарата (жив / мёртв) |
| Ориентация кувыркающегося тела, ось и скорость вращения | поворот силуэта между полосами | ось ~10°, скорость от ~2°/с у тел > 10 м | ADR (захват), прогноз светимости |
| Центр масс относительно силуэта | центр вращения в последовательности полос; масса и материалы по модели | метры у больших тел | точная OD (фотоцентр ≠ центр масс), ADR |
| Материалы, отражательная способность | НМНК по группам материалов в 10 полосах | спектр по группам | идентификация, старение, модели светимости |
| Площадь сечения, отношение площадь/масса (A/m) | модель в позе + масса из каталога | ±10–20 % | торможение атмосферой и давление света → прогноз орбиты |
| Светимость и блики | яркость в полосах + BRDF модели | — | астрономия, проверка законов ориентации |
| Фрагментация, отделившиеся части | дополнительные пятна рядом с объектом | от ~2 м | события разрушения, рост мусора |

## 2. Состав системы

```
каталоги (SATCAT, GCAT, DISCOS) ─┐
орбиты (TLE / SupGP / OMM, архив) ┼─► прогноз пересечений с кадрами ─► обнаружение (согласованный фильтр по полосам)
снимки (Sentinel‑2 L1C/L2A, …)  ─┘                                              │
                                                                                 ▼
каталог моделей (геометрия, шарниры, материалы) ─► модель прямого счёта ◄─ измерения пролёта: положения, яркости, силуэты
законы ориентации класса ───────────────────────┘           │
                                                            ▼
                                 оценка параметров пролёта (одна и та же для всех объектов)
                                                            │
                                                            ▼
                    объектный уровень: орбита, A/m, B*, история ориентации, вращение, манёвры
                                                            │
                                                            ▼
                     выдача: карточка объекта, ряды по времени, поправки к орбитам, досье для ADR
```

### 2.1. Каталог моделей (есть: 129 моделей, правила назначения для всех объектов)
- **Источники.** NASA 3D Resources, satvis‑3d‑models, KeepTrack (ступени), Sketchfab (CC‑BY). Параметрические модели — по размерам из GCAT.
- **Назначение модели.** NORAD → шина GCAT → имя → правила ступеней (форма, ракета, размер) → параметрическая.
- **Шарниры.**
  - Если в модели есть кинематическое дерево (у МКС IGOAL — `ALPHA_ROT` → `BETA_ROT`), берутся оно.
  - Иначе шарниры ищутся по геометрии:
    - первая ось — от центра к корню крыла;
    - вторая ось — вдоль длины крыла, если корень далеко и крыло стоит поперёк;
    - панели внутри ядра корпуса считаются неподвижными.
- **Нужно добавить:**
  - массово‑инерционные свойства: масса из DISCOS/GCAT, распределение массы по частям, центр масс, тензор инерции;
  - материалы по частям с BRDF из библиотеки: солнечные элементы, MLI (золото/серебро), белая краска, алюминий, сопло;
  - выверку осей для моделей без неё, по нескольким пролётам одного объекта (п. 3.4).

### 2.2. Модель прямого счёта (одна для всех)
- **Состояние объекта на момент полосы b:**
  - положение центра масс r(t_b) по орбите плюс поправка;
  - ориентация q(t_b): закон класса либо q₀ ⊗ exp(ω·(t_b − t₀)) для вращающихся тел;
  - углы приводов панелей по закону: наведение на Солнце по всем найденным осям;
  - смещение фотоцентра от центра масс.
- **Освещение.** Солнце по эфемериде, свечение Земли, затенение частями модели (трассировка лучей), BRDF материалов.
- **Датчик.**
  - точные моменты съёмки полос и смещения детекторов (из метаданных гранулы, L1C);
  - функция рассеяния точки (PSF/MTF) каждой полосы, смаз за время накопления;
  - геометрия сканера: для быстрого объекта сканер — это ортографическая проекция вдоль нуль‑вектора якобиана полосы (THEORY §23).
- **Фон.** Тот же кадр без объекта: медиана соседних пикселей и снимков этой точки в другие даты.

### 2.3. Оценка параметров пролёта (одна для всех)
1. **Астрометрия.** Центр пятна каждой полосы → положение в момент полосы. Подгонка поправки орбиты: сдвиг вдоль следа,
   поперёк, по радиусу и сдвиг по времени. Учёт смещения фотоцентра от центра масс по модели в позе.
2. **Выбор закона ориентации.** Для каждого закона класса поза вычисляется. Подбираются только положение и яркости
   материалов. Уточнение по половине полос, проверка на другой половине. Позы, неразличимые снимком (СКО вершин
   < max(1 м, 6 % размера)), выдаются вместе.
3. **Нештатность.** Свободная оценка поворота (вектор поворота). Объект помечается нештатным, если она лучше лучшего
   закона более чем на порог в эффективном χ² и поза различима.
4. **Вращение.** Для ступеней, обломков и нештатных объектов оцениваются ось и скорость вращения по силуэтам полос:
   q(t) = q₀ ⊗ exp(ω t), а центр масс — как центр вращения. В одном пролёте до ~2 с: видно вращение быстрее ~2°/с у тел
   больше 10 м.
5. **Материалы и спектр.** Отражательная способность групп материалов по полосам (НМНК). Сравнение с библиотекой спектров.
6. **Значимость.**
   - Невязки нормируются на κ — несоответствие модели снимку сверх шума.
   - Запас выбора и порог нештатности задаются в эффективном χ².
   - Ошибки оцениваются бутстрепом по полосам.

### 2.4. Объектный уровень (по всем пролётам объекта)
- **Орбита.** Совместная подгонка всех пролётов и публичных TLE: числовое интегрирование с торможением и давлением
  света (A/m и коэффициент отражения из модели). На выходе — уточнённые элементы и ковариация, сравнение с SupGP.
- **Манёвры.** Скачок поправки орбиты между пролётами, больший ожидаемого.
- **Вращение.** Эволюция оси и скорости: затухание (вихревые токи, YORP), прецессия. Прогноз на дату миссии ADR.
- **История ориентации.** Режимы во времени: штатный, сохранение, кувыркание. Признак «аппарат мёртв».
- **Выверка осей модели.** Для моделей без выверенных осей перебираются 24 поворота «куба» осей модели совместно по
  всем пролётам объекта с законом «на Землю». Побеждает поворот, согласный со всеми пролётами.

### 2.5. Выдача
- **Карточка объекта:**
  - модель и уверенность назначения;
  - размеры;
  - режимы ориентации по датам;
  - вращение (ось, скорость, ошибка);
  - центр масс и фотоцентр;
  - A/m;
  - спектр материалов;
  - поправки к орбите.
- **Для каталога.** Поправки TLE на эпохи пролётов, ковариации, признак манёвра.
- **Для ADR:**
  - вращение и его прогноз;
  - точки захвата по модели (сопло, переходник, кромки);
  - центр масс и тензор инерции;
  - выступающие элементы (антенны, панели);
  - риск при сближении.
- **Публикация.** Страницы, видео, сравнение «снимок ↔ модель» по полосам.

## 3. Проверка (без неё параметры не выдаются)
1. **Синтетика в настоящем фоне** (`scripts/inject_pose.py`, распространить на все параметры). Объект с известными
   параметрами в настоящих окнах снимка → доля верных законов, ошибка позы в метрах, калибровка порога нештатности,
   ошибки положения и вращения.
2. **Объекты с известной правдой:**
   - МКС: опубликованная ориентация TEA (ψ −4…−10°, θ −2…−12°, φ 0…1°; NASA), углы SARJ/BGA;
   - Starlink: опубликованные режимы панелей (отворот у терминатора, ребром к лимбу Земли);
   - спутники лазерной дальнометрии (ILRS) с известным вращением;
   - ступени с кривыми блеска из открытых баз (MMT‑9) и радарными изображениями.
3. **Перекрёстная проверка между снимками.** Тот же объект в соседние дни должен дать согласованные орбиту, A/m,
   спектр и ось вращения.
4. **Отсутствие объекта.** Нулевые окна (тот же кадр, другое место) задают ложные тревоги каждого параметра.

## 4. Порядок работ

| Этап | Что | Готово, когда |
|---|---|---|
| 1 | Астрометрия по полосам: положение, время, поправка TLE, фотоцентр − центр масс | на МКС и Starlink поправки согласуются с SupGP до 10–20 м |
| 2 | Вращение по силуэтам полос: ось и скорость, центр вращения | синтетика: скорость ±20 %, ось ±15° для тел > 10 м |
| 3 | Материалы: BRDF‑библиотека, спектры по группам | спектры солнечных элементов и MLI отличаются на синтетике и на Starlink/МКС |
| 4 | Объектный уровень: совместная OD по пролётам, A/m, B*, манёвры | для 5+ пролётов одного объекта: ковариация реалистична (проверка по SupGP) |
| 5 | Выверка осей моделей по нескольким пролётам | 37 моделей NASA без выверки получают оси или помечаются «не определено» |
| 6 | Масса и инерция в каталоге моделей, точки захвата для ступеней | досье ADR для всех ступеней на орбитах < 786 км |
| 7 | Другие сенсоры: Landsat 8/9 OLI (тоже сканер с разносом полос), Sentinel‑3, коммерческие | тот же конвейер на OLI без правок |
